architecture_notes.md

Cara kerja sistem Web Screenshot Beautifier jika dikembangkan ke tahap produksi:

1. Headless Browser Capture

Menggunakan Puppeteer / Playwright di server Node.js atau memanggil API seperti Microlink (yang aktif di web ini) untuk merender URL target ke resolusi 1280x800.

2. CSS Frame & Color Engine

Membungkus hasil gambar dengan kontainer DOM yang memiliki header ala OS/Browser serta latar belakang CSS variabel yang mendukung color picker (Solid HEX & Linear Gradient).

3. Client-Side Rasterization

Menggunakan html2canvas dengan rasio scale: 2 agar hasil unduhan PNG tajam di layar Retina.
